# Deviations from Pre-Registration

Every change to the frozen `PREREGISTRATION.md` (tag `prereg-v1.0`) is logged here. The pre-registration file itself is never edited.

|---|---|---|---|---|

| 2026-10-19 | 6 (yen move, condition 1; decision B) | If there is no fixing on day t-5, the 5-day yen return uses the last fixing on or before t-5. | 2026-10-19 | 6 (yen volatility, condition 2; decision C) | 20-day realized volatility uses only available daily `r_yen` values in the last 20 NYSE days, with sample standard deviation (ddof = 1), annualized by sqrt(252).
